# Recipe & Ingredient Management Application

Это веб-приложение для управления рецептами и ингредиентами, построенное на основе Spring Boot, Spring Data JPA, Thymeleaf и Swagger. Проект демонстрирует реализацию CRUD-операций для двух сущностей: **рецептов** и **ингредиентов**, связанных отношением _многие ко многим_.

## Функциональность

- **Управление ингредиентами:**
  - Просмотр списка всех ингредиентов.
  - Просмотр подробной информации об ингредиенте.
  - Создание нового ингредиента.
  - Удаление ингредиента по идентификатору.

- **Управление рецептами:**
  - Просмотр списка всех рецептов с указанием входящих ингредиентов.
  - Создание нового рецепта с выбором ингредиентов (через форму с чекбоксами).
  - Редактирование существующего рецепта (изменение названия и состава ингредиентов).
  - Удаление выбранного рецепта.
 
  ## API эндпоинты

### Ингредиенты
- **GET /ingredient** – получение списка всех ингредиентов.
- **GET /ingredient/{id}** – получение информации об ингредиенте по ID.
- **GET /ingredient/new** – отображение формы для создания нового ингредиента.
- **POST /ingredient** – создание нового ингредиента.
- **GET /ingredient/delete** – отображение формы удаления ингредиента.
- **POST /ingredient/delete** – удаление ингредиента по ID.

### Рецепты
- **GET /recipe** – получение списка всех рецептов с ингредиентами.
- **GET /recipe/new** – отображение формы для создания нового рецепта.
- **POST /recipe/new** – создание нового рецепта с выбранными ингредиентами.
- **GET /recipe/edit** – отображение формы для редактирования рецепта.
- **POST /recipe/update** – обновление данных рецепта.
- **POST /recipe/delete** – удаление выбранного рецепта.


## Технологии

- **Java 11+**
- **Spring Boot** – для создания REST и MVC приложения.
- **Spring Data JPA** – для работы с базой данных.
- **Thymeleaf** – для реализации шаблонов HTML.
- **Swagger / OpenAPI** – для документирования REST API (аннотации присутствуют в контроллерах).
- **Maven** – для управления зависимостями и сборки проекта.

## Заключение
Этот проект демонстрирует реализацию веб-приложения для управления рецептами и ингредиентами с использованием современных технологий Spring.
